# Web Calculator

- it's simple web calculator to do the basic operations (add, subtract, multiply, divide)

## Install & Run

```bash
git clone https://github.com/Abdalr7man-M/web-calculator
cd web-calculator
npm install
npm run dev
```

## URLs

- `http:localhost:3000/{operation-name}?a=3&b=4`
  - you can use in operation-name `add` , `subtract` , `multiply`, `divide`
  - to do this operations on `a` & `b` parameters.
